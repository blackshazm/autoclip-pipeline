MÓDULO 0: RADAR YOUTUBE

Detecção de Outliers e Extração Otimizada

O Radar escuta os feeds XML de canais cadastrados em config/channels.json. Ao detectar um novo upload, calcula a velocidade de visualizações por hora:

VPH = total_views / ((now - published_at_hours) || 1)
  • Ignora vídeos já registrados no banco local.
  • Download de vídeos longos somente se VPH ultrapassar o multiplicador (ex: 2.5x).
  • Uso de rotação de user-agents e cookies para segurança de rede.

Engenharia & Operação

Comandos de Inicialização e Deploy

Execute o pipeline localmente ou coloque os daemons em segundo plano.

Bash / PowerShell 
# 1. Configurar variáveis de ambiente
cp .env.example .env

# 2. Instalar dependências Python
pip install -r requirements.txt

# 3. Executar o pipeline autônomo completo
python run_pipeline.py

# Ou rodar o script de demonstração end-to-end:
python demo_full_pipeline.py
Linux Server (deploy/*.service) 
# Copiar os arquivos de serviço para o systemd
sudo cp deploy/*.service deploy/*.timer /etc/systemd/system/
sudo systemctl daemon-reload

# Ativar e iniciar os serviços autônomos
sudo systemctl enable --now clip-radar.timer
sudo systemctl enable --now clip-ingest.service
sudo systemctl enable --now clip-publish.service
sudo systemctl enable --now clip-watchdog.service
Pytest com Cobertura 
# Rodar todos os testes unitários e de integração
pytest -v

# Rodar especificamente os testes de banco e transação WAL
pytest tests/test_database.py -v

# Verificar testes de quota e rate limit
pytest tests/test_publish_quota.py -v
Publicar esta página no GitHub Pages
