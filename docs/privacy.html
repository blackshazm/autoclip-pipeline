Política de Privacidade

Última atualização: 29 de setembro de 2026

Aviso sobre Serviços da API do YouTube: Esta aplicação utiliza os Serviços da API do YouTube (YouTube API Services). Ao utilizar esta esteira, os usuários concordam com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

1. Visão Geral

O AutoClip Pipeline Engine é uma ferramenta de automação e edição autônoma de vídeos de formato curto (YouTube Shorts e TikTok). Esta Política de Privacidade explica como informações e credenciais são tratadas durante a operação do software.

2. Dados Acessados e Coletados

O aplicativo opera sob o princípio de mínimo privilégio, acessando estritamente:

  • Dados de Autenticação OAuth: Tokens de acesso fornecidos pelo usuário via Google OAuth 2.0 para viabilizar o upload e gerenciamento de vídeos no canal autorizado.
  • Metadados Públicos de Vídeos: Título, contagem de visualizações públicas e data de publicação via feeds RSS públicos para cálculo do algoritmo VPH (Views Per Hour).
  • Arquivos de Mídia: Processamento estritamente local de arquivos de vídeo e áudio em sua própria máquina ou servidor dedicado.

3. Armazenamento e Segurança das Informações

Todas as credenciais (como client_secret.json e tokens OAuth de atualização) são armazenadas exclusivamente de forma local no ambiente onde o pipeline é executado.

  • Nenhum dado, token, senha ou vídeo é transmitido para servidores de terceiros ou comercializado.
  • O código é de execução determinística local com banco de dados SQLite operando em modo WAL restrito ao computador do usuário.

4. Uso dos Dados da API do YouTube

Em conformidade com a Google API Services User Data Policy, o uso e a transferência de informações recebidas das APIs do Google aderem aos requisitos de Uso Limitado (Limited Use Requirements).

O acesso é utilizado exclusivamente para:

  • Verificar a cota diária de publicação (YouTube Data API v3).
  • Realizar o upload de vídeos (Shorts) autorizados pelo proprietário do canal.

5. Como Revogar o Acesso aos Seus Dados

O usuário pode revogar o acesso do AutoClip à sua conta do Google a qualquer momento através da página de configurações de segurança do Google:

👉 Configurações de Segurança do Google (Permissões de Aplicativos)

Além disso, a exclusão do arquivo local config/youtube_token.json remove imediatamente o token do ambiente local.
